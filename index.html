Về tôi

Xin chào! Tôi là Trần Tuấn Anh, sinh viên chuyên ngành Công nghệ Thông tin tại Trường Đại học Công nghệ Sài Gòn (STU) với niềm đam mê mãnh liệt về Bảo mật mạng (Cybersecurity). Tôi đã bảo vệ thành công luận văn tốt nghiệp đề tài AI-assisted Threat Detection using Multi-Source Log Analytics với điểm 7.9/10.

Tôi bắt đầu hành trình trong lĩnh vực bảo mật thông qua các cuộc thi Capture The Flag (CTF), nơi tôi rèn luyện và phát triển kỹ năng về điều tra số (OSINT), phân tích mã độc, và tư duy giải quyết vấn đề.

Với kinh nghiệm tham gia các cuộc thi CTF quốc tế như Cyber Apocalypse CTF 2025: Tales from Eldoria, tôi đã chứng minh khả năng làm việc dưới áp lực và giải quyết các thách thức bảo mật phức tạp.

Song song với bảo mật, tôi làm việc sâu với Machine Learning & LLM: tự cài đặt Transformer từ đầu bằng PyTorch, fine-tune Qwen3-4B với QLoRA, xây RAG pipeline cho trợ lý AI tiếng Việt offline (Luna), và ứng dụng anomaly detection vào phát hiện threat từ log hệ thống. Tôi tin giao điểm giữa AI và Security chính là hướng đi của mình.

Luna — Trợ lý AI tiếng Việt chạy hoàn toàn offline

Python PyTorch Transformers QLoRA / PEFT FAISS RAG PySide6

Role: Cá nhân — thiết kế & triển khai toàn bộ end-to-end

  • Tự cài đặt GPT-style Transformer decoder from scratch bằng PyTorch: self-attention với causal masking, multi-head attention, residual + LayerNorm, training loop và autoregressive sampling.
  • Fine-tune Qwen3-4B-Instruct với QLoRA (4-bit bitsandbytes quantization, LoRA adapters qua PEFT, SFTTrainer) trên persona dataset tự xây dựng.
  • Xây RAG pipeline trên 476 tài liệu: multilingual E5 embeddings, FAISS cosine index, hybrid semantic + keyword retrieval với title weighting và score threshold để hạn chế hallucination.
  • Tích hợp speech offline (faster-whisper STT, viXTTS TTS) và overlay UI bằng PySide6; kèm pytest suite 8/8 passing + linting ruff/black.

Anomalous Email (Phishing) Detection using Machine Learning

Python Scikit-learn Random Forest NLP RFECV
  • Xây dựng pipeline ML để phát hiện email bất thường, trực tiếp đối phó với Social Engineering & Phishing attack vectors.
  • Trích xuất feature từ headers/bodies của email, áp dụng tiền xử lý nâng cao chống Unicode homograph attacks và HTML ẩn của attacker.
  • Tối ưu feature space từ 20,000 xuống còn 5,000 features quan trọng dùng Recursive Feature Elimination (RFECV).
  • Train & đánh giá Random Forest classifier, so sánh với baseline; đánh giá bằng precision / recall / F1 trên tập held-out.

AI-assisted Threat Detection using Multi-Source Log Analytics for University Systems

Python Scikit-learn Fluentbit Loki PostgreSQL FastAPI Grafana Docker

Role: Project Lead & Lead Author — feature engineering, ML engine, risk scoring, paper writing · Bài báo Q3 đang chuẩn bị

  • Đã bảo vệ thành công luận văn tốt nghiệp (Đại học Công nghệ Sài Gòn, 2026) với điểm tổng kết 7.9/10.
  • Xây dựng framework phân tích log đa nguồn tích hợp AI để phát hiện threats trong môi trường đại học (target: small/medium universities thiếu SOC).
  • Pipeline 6-layer: Log Sources (pfSense, Linux auth, Nginx, FastAPI, PostgreSQL) → Fluentbit → Loki → Feature Extraction → ML Engine → Risk Scoring → Grafana SOC-lite Dashboard.
  • Áp dụng ensemble anomaly detection: Isolation Forest, LOF, One-class SVM — kết hợp voting cho final anomaly score.
  • Feature engineering nâng cao: sliding windows, IP entropy, request rate, login fail count; synthetic attack generation (SSH brute-force, endpoint scanning, credential stuffing).
  • Đánh giá benchmark trên CICIDS / UNSW-NB15 datasets; metrics: Precision · Recall · F1 · ROC-AUC.
